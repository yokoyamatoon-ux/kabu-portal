# デザイン設計書：金（ゴールド）投資の価値と最新相場（学ぶシリーズ エピソード15）

## 1. 概要
本エピソードは、昨今注目を集めている「金（ゴールド）投資」をテーマに、初心者が陥りがちな「上がっているから全力投資」という誤解を解き、金の安全資産としての本質的な強み（有事の金）と弱み（金利を生まない）、そして2026年現在の激しい相場乱高下（1月の最高値5600ドルから2月の4000ドルへの急落）の理由をわかりやすく解説する。

## 2. キャラクター構成・ストーリー展開
- **マネ太**: 金相場高騰のニュースを見て全財産を突っ込もうと興奮する。
- **ミライ**: 2026年2月に起きた急落を指摘し、マネ太を冷静に引き戻す。
- **カブ先生**: 金の二面性（実物資産としての安全性 vs 金利なしの弱点）と、米利下げ期待後退による急落背景を解説し、「ポートフォリオの保険（5-10%）」として付き合うべきと喝を入れる。

## 5. 解説コラム設計
### タイトル案
実物資産「金（ゴールド）」投資の価値とは？2026年最新相場の乱高下から学ぶ、正しい付き合い方

### 構成
1. **なぜ金は「安全資産（有事の金）」と呼ばれるのか？**
   - 希少性（地球上のプール約4杯分のみ）と、実物として存在すること（価値がゼロにならない）。
2. **2026年の金相場の激しい動き**
   - 2026年1月に史上最高値5,600ドル台を付けた背景（中東情勢緊迫化、インフレヘッジ、中央銀行のドル離れ）。
   - 2026年2月に4,000ドル近辺へ急落した要因（米インフレの粘着によるFRB利下げの先送り、米金利高止まりによるドル高）。
3. **金投資のメリットとデメリット**
   - メリット：インフレヘッジ、無価値化リスクなし、地政学的リスクの緩衝材。
   - デメリット：利息・配当を生まない（キャピタルゲインのみ）、為替ヘッジなしによる円高リスク。
4. **初心者向け実践方法**
   - 金は資産運用の主役ではなく「脇役（最強の保険）」。
   - 全体の5〜10%の保有目安。
   - 純金積立、ETF、金地金などの投資アプローチ。
