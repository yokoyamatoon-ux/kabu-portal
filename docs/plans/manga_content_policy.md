# マンガ解説記事コンテンツ（description_long）の執筆・更新ルール

マンガの下部に表示される解説記事（`manga.json` の `description_long`）は、**「マンガ内容の単純ななぞり（要約）」ではなく「マンガの延長（深化）」**にする必要があります。以下のルールを厳守して執筆してください。

## 1. 基本方針：マンガ内容の延長
- マンガのストーリーやセリフと同じことをただ繰り返す（狼狽売りはダメ、等だけを述べる）構成は禁止します。
- マンガで学んだ「原則・理論」が、現実社会でどのように適用されるのかを示すため、**過去の実例**を用いて解説を拡張してください。

## 2. 必須構成要素
解説記事には、以下の要素を必ず含めてください。

### ① 過去の具体的な実例（良い例・悪い例）
- **良い例（成功・回復の実例）**: 一時的な問題から復活を遂げた企業や、原則通りに動いて成功した実例。
- **悪い例（失敗・警告の実例）**: 致命的な不正で崩壊した企業や、原則を破って大損した実例。
- **理由の解説**: なぜその実例が「良い/悪い」結果になったのか、ビジネスモデルや信用の観点から解説を添えること。

### ② 信頼できるソース（Source）の提示
- 実例には必ず、信頼できる報道（日本経済新聞等）や公的機関の一次情報（国税庁、財務省、適時開示等）のリンクを貼る。
- **リンクの記述ルール**:
  HTML形式で、必ず `target="_blank"` を指定し、クラス `text-primary hover:underline` を付与する。
  例: `<a href="URL" target="_blank" class="text-primary hover:underline">日本経済新聞：記事タイトル</a>`

## 3. 品質チェック（翻訳跡の排除）
- 執筆時、あるいはAIによるコンテンツ作成時に、英単語の直訳跡（例: 「〜 of 強み」「ブランドイメージ is 一時的」などの `of` や `is`）が混入していないか徹底して確認し、自然な日本語のみで記述する。
- HTMLタグの整合性（閉じタグ漏れがないかなど）をJSONに組み込む前に検証する。

## 4. マンガ画像生成プロンプトの記述ルール
マンガ画像生成用のプロンプト（2ページ、各5コマ等の構成指示）を作成する際は、AIがコマ割りやキャラクターの配置、セリフの読み順を正しく解釈できるように、以下のルールを厳守して記述してください。

### ① コマ順とコマ割り
- コマ順は「右上」「左上」「右中」「左中」「下段」の5コマ構成とし、右から左へ読む日本のマンガ形式に統一する。
- コマ番号は記載しない。

### ② キャラクターとフキダシの位置指定
- 1つのコマに複数人（2人以上）が登場して会話をする場合は、画像生成AIが混乱しないように、キャラクターの左右の立ち位置を「右側に〇〇が立ち、左側に〇〇が立っている」のように明記する。
- セリフの読み順（右上から左下）に合わせて、フキダシの位置（右上、左下など）を明確に指定する。先に発言するキャラのフキダシを「右上」、後から発言するキャラのフキダシを「左下」に配置する。
  例:
  右上にミライのフキダシ：「〜〜」
  左下にマネ太のフキダシ：「〜〜」
