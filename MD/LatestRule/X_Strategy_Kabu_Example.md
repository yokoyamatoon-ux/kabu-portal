# カブ先生版 驚き屋リポスト型・スレッド投稿成功例 (投資詐欺・AIトレード注意喚起)

## 概要
- **目的**: 海外や国内でバズっている金融・投資関連の動画（例：AI自動売買ツール、絶対に儲かる系の怪しい投稿など）を引用し、カブ先生（権威あるおじいちゃん先生）の視点で解説・警鐘を鳴らすことで、X（Twitter）のインプレッションと信頼性を獲得する。
- **導線**: 最終ツイートから「お金の学び場」ポータルの関連コラムや「お金のウラ事情ファイル」へ誘導する。
- **実装上の注意点**: 
  - **API制限回避**: 現在のAPIキー（v1.1/v2）では引用リポスト（Quote Tweet）やスレッド返信でエラー（401/403）が出るケースが多いため、PlaywrightによるEdgeブラウザ自動化（`.chromium_scout` プロファイル）を使用。
  - **要素のクリックエラー回避（最重要）**: Xの画面上には透明なポップアップやトースト通知が被さるため、Playwright標準の `.click()` や `click(force=True)` はタイムアウトエラーになります。必ず **`element.evaluate("node => node.click()")`** を使用して内部DOMからクリックを発火させてください。
  - **文字数制限（140字単位）の厳守**: Xでは全角=2、半角=1、URL=23としてカウントされ、合計280以内（全角140字）である必要がある。スレッドの各投稿はこの制限を満たすよう設計。
  - **ツリーの繋ぎ間違い防止（★最重要）**: プロフィール画面で安易に「一番上」のリンクを取得してリプライを繋げようとすると、**「固定されたツイート（Pinned Tweet）」に誤ってぶら下がってしまう**。必ず「引用リポスト特有のテキスト」でDOM要素を検索し、正しい親ツイートのIDを特定してからスレッド化（リプライ）する。
  - **ペルソナの徹底**: カブ先生の口調（「フォッフォッフォ！」「～じゃ」「～ぞい」「喝！！」）を厳守し、親しみやすさと厳格さを両立させる。

## AIアシスタントへの指示ルール（重要）
- ユーザーから「**Xの引用ポスト（リポスト）やって**」と指示された場合の必須ワークフロー：
  1. まず、**海外・国内の「金融・投資」に関する最新ニュースや話題のトピック（株価、AI投資、詐欺事例など）をWebリサーチ**する。
  2. その中から、カブ先生の「お金の学び場」のコンセプト（初心者への投資教育、詐欺への警鐘など）に合致するポストや記事のURLを選定する。
  3. 選定したURLを用いて、以下の「全4ポスト構成（フック・警鐘・本質・ブログ誘導）」でカブ先生のペルソナに合わせた台本を作成し、投稿プロセスへ進む。
  ※特定の企業やトピックに固執せず、常に**金融・投資の学び**に直結する最新ニュースを優先して自律的にリサーチを行うこと。
