# コンテンツ更新・記事作成マスターチェックリスト

このチェックリストは、カブ先生ポータル（お金の学び場）のコンテンツ更新時に必ず確認すべき項目です。

---

## 🛑 【最重要】更新時必須チェック項目

### 1. アイキャッチ及びマンガ画像
- [ ] **日本語プロンプト作成:** 各コマの状況・キャラの表情を詳細に記述した日本語プロンプトを作成したか？
- [ ] **（AI禁止事項）画像生成:** AIによる `generate_image` ツールの使用は行わず、ユーザーにプロンプトを提示して生成を依頼したか？
- [ ] **X Server 稼働確認:** `netstat` 等で port 5000 が LISTENING 状態か確認し、落ちていれば `server.py` を再起動したか？
- [ ] **パス指定の正確性:** ユーザーから受け取った画像、または合意した画像パス（例：`ColumnYYYYMMDD.png`）が JSON 内に正しく記述されているか？


### 2. キャラアイコン表示・スピーカー設定
- [ ] **スピーカーキー:** `speaker` に正しい値（`"kabu"`, `"maneta"`, `"mirai"`, `"urakane"`, `"hikari"`) が設定されているか？
- [ ] **アイコンの整合性:** 指定したキャラとアイコン画像、吹き出しの色（左/右配置）が一致しているか？

### 3. 各担当（キャラクター）の設定と制限
- [ ] **セクション制限:** 「マンガで学ぶ」にウラ金さんが登場していないか？（カブ先生、マネ太、ミライのみ）
- [ ] **ペルソナ遵守:** カブ先生（〜じゃ、〜のう）、マネ太（〜っす）、ウラ金（ヒッヒッ…）の口調が徹底されているか？
- [ ] **エモート設定:** 各発言の `emote` ("normal", "surprise") はシーンに合っているか？

### 4. 文字数・ボリュームの最適化
- [ ] **マンガ解説文:** 1,500〜2,000字程度の充実した解説が含まれているか？
- [ ] **メタタイトル:** 32文字以内（キーワード左寄せ）で収まっているか？
- [ ] **メタディスクリプション:** 80〜120文字程度で、記事のメリットが書かれているか？

### 5. タイトル・SEO設計
- [ ] **タイトル形式:** 末尾に ` | カブ先生のお金の学校` が含まれているか？
- [ ] **定義段落:** 冒頭に「[キーワード]とは、〜です。」というAIO対策の定義文があるか？
- [ ] **ステマ表示:** 広告リンクを含む場合、冒頭に「※本ページには広告・アフィリエイトリンクが含まれます。」があるか？

### 6. SNS連携・拡散 (ルーティン)
- [ ] **X (Twitter) ドラフト更新:** `x_dashboard/draft.json` を最新記事の内容で更新し、アイキャッチ画像を紐付けたか？
- [ ] **AI Workstation 案内:** ユーザーに AI Workstation の X Manager で同期・投稿するよう案内したか？
- [ ] **note 下書き作成:** note-mcp を使用して、新着記事への誘導（チラ見せ）用下書きを作成したか？

### 7. デプロイ・サイト反映確認
- [ ] **デプロイ実行:** `python deploy_kabu.py` を実行し、ビルドとFTPアップロードがエラーなく完了したか？
- [ ] **反映確認:** 本番（またはプレビュー）サイトで **Ctrl + F5** (強制リロード) を行い、新着記事の表示を確認したか？
- [ ] **リンク動作:** 新規ページや内部リンクが正しく動作し、画像が表示されているか？
