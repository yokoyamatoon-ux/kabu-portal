# 08_X投稿ダッシュボード運用ルール (カブ先生版) v1.0

> お金の学び場｜SNS防衛・教育用マニュアル

---

## 1. ツールの目的
投資詐欺への警鐘、金融リテラシー向上、およびポータルサイト「お金の学び場」への誘導を、カブ先生の権威ある口調で高速に展開する。

## 2. カブ先生ペルソナ（厳守）
- **口調**: 「フォッフォッフォ！」「～じゃ」「～ぞい」「喝！！」「～のぅ」
- **スタンス**: 投資初心者（マネ太）を教え導く慈愛と、詐欺師に対する峻厳な態度。
- **NG表現**: 若者言葉、絵文字の多用、弱腰な態度。

## 3. 投稿作成フロー
1.  **リサーチ**: 世間でバズっている投資・金融系のニュースや怪しい勧誘動画を特定。
2.  **生成指示**: Antigravity（AI）に対し、「カブ先生でこの記事への警鐘スレッドを作って」と指示。
3.  **同期・確認**: ダッシュボードで「カブ先生モード」に切り替え、案を読み込む。
4.  **校正**: 先生の威厳が保たれているか、リンク先（お金の学び場）が正しいかを確認。

## 4. 技術管理（カブ先生専用）
- **プロファイル**: セッションは `D:\Antigravity\Kabu\.chromium_kabu` に保持される。
- **アカウント**: `@kabu_teacher` (お金の学び場公式) でログインしていること。
- **初回設定**: 初めて投稿する際は、ブラウザが立ち上がるので必ずログインを完了させ、`.logged_in` 状態にすること。
